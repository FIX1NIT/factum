# FACTUM

**Карта дела, где у каждого факта есть источник.** Платформа для юристов: загружаете материалы дела, ИИ строит карту (участники, документы, хронология, доказательства, нормы права), а программа проверяет каждую цитату по тексту документа. Решает человек, программа не определяет виновность.

Команда LawAttack: Ильяс, Файоз, Джалол. LexHackathon 2026, трек «Юридические услуги».

## Что умеет МВП

- Загрузка TXT, MD, Word (DOCX), RTF, ODT, PDF, JPG, PNG до 400 КБ на файл; ИИ читает сканы и картинки.
- Карта дела: участники, документы, источники, хронология, доказательства, нормы права, ИИ-юрист (чат).
- Семь ролей (судья, прокурор, следователь, адвокат, студент, гражданин, нейтральный), интерфейс на русском, узбекском и английском.
- Проверка цитат: если ИИ приводит цитату, которой нет в документе, пункт отбрасывается.
- Нормы права берутся с lex.uz (текст статьи скачивает программа), а не из памяти ИИ.
- Кнопка обезличивания: паспорта, ПИНФЛ, телефоны, почты, карты, даты рождения и ФИО заменяются метками в браузере до отправки ИИ.
- Дела хранятся в браузере пользователя, на сервере не сохраняются.

## Как устроено

- Интерфейс: HTML, CSS и JavaScript без фреймворков, папка `public/`.
- Сервер: Node.js 22 без сторонних пакетов (`host.mjs`, `ai.mjs`, `extract.mjs`, `lexnorms.mjs`).
- ИИ: Claude через API Anthropic. Ключ задаётся переменной окружения на хостинге и в репозитории не хранится.
- Защита: код доступа и лимиты запросов к ИИ.
- Развёртывание: GitHub и Railway, сайт обновляется из репозитория автоматически.

## Запуск

Нужен Node.js 22 или новее. Скопируйте `.env.example` в `.env`, впишите свой ключ API и код доступа, затем:

```
npm start
```

Без ключа ИИ сайт работает на заготовленных ответах для учебного дела.

## Ограничения

Автотестов нет, проверяли вручную на учебных делах. Нет аккаунтов и серверного хранения дел (это решение по приватности). Нормы права только из подключённых документов lex.uz (ГК, ТК, КоАП, УК, Закон об образовании, пункты ПДД). Картинки и сканы PDF обезличить заранее нельзя. Текст дела при работе ИИ уходит провайдеру ИИ.

Все примеры дел вымышлены. Неофициальный учебный прототип. Не является государственным сервисом и юридической консультацией.
